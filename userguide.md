## UK Weather Finder

> **Location:** Top card

Search for current weather conditions at any UK location.

### How to use

1. Type a UK location name into the search box.
2. Click the **Search** button.
3. Current weather results will appear below the search bar.

### What you'll see

| Field | Description |
|---|---|
| Weather description | A short summary of current conditions (e.g. "Partly cloudy") |
| Temperature | Current temperature in °C |
| Feels like | Adjusted temperature accounting for wind and humidity |
| Humidity | Current humidity as a percentage |
| Weather symbol | An icon representing the current conditions |

### Notes

- The search is **not case sensitive** — `london`, `London`, and `LONDON` all work.
- **Spelling must be correct.** If a location is misspelled, no result will be returned. If you see no output, double-check the spelling of your location.

## Hottest UK City Right Now

> **Location:** Bottom-left card

Find which UK city currently has the highest temperature with a single click.

### How to use

1. Click the **Find Hottest City** button.
2. The app queries current temperatures across a comprehensive dictionary of UK cities.
3. The warmest city is identified and displayed.

### What you'll see

| Field | Description |
|---|---|
| City name | The UK city with the highest current temperature |
| Temperature | Current temperature in °C |
| Condition | A description of current weather conditions |
| Weather symbol | An icon representing the current conditions |

### Notes

- Because this feature queries many cities simultaneously, results can take **a few minutes** to return.
- A **spinning sun symbol** will appear while the search is in progress — please wait for it to complete without clicking again.

## Best UK Holiday Spot

> **Location:** Bottom-right card

Find the best UK city for a future date based on the highest temperature and lowest chance of rain.

### How to use

1. Select a future date using the date picker.
2. Click the **Find** button.
3. The app evaluates forecasts across UK cities, scoring each by temperature and rain probability.
4. The recommended holiday spot is displayed with its forecast details.

### What you'll see

| Field | Description |
|---|---|
| Best city | The UK city with the optimal forecast for your chosen date |
| Forecast temperature | Predicted temperature in °C |
| Rain probability | Chance of rainfall as a percentage |
| Weather symbol | An icon representing the forecast conditions |

### Notes

- **Forecast limit: 15 days.** Weather data is only available up to 15 days ahead. Selecting a date beyond this window will not return a result — choose a date within the next 15 days.
- Like the Hottest City feature, this query can take **a few minutes** to complete. The spinning sun symbol will show while results are loading.

| Tip | Detail |
